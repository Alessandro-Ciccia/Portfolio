## Overview

This project is the public portfolio you are browsing now. The goal is to keep the visual language polished and minimal while making the content easy to evolve over time.

## What I focused on

- A responsive layout built around reusable sections
- A liquid-glass visual system with dark and light themes
- Content-driven project pages written in Markdown
- SEO basics with metadata, sitemap and robots configuration

## Notes

Each personal project can have its own Markdown file, cover image, screenshots, external website and repository link. To add a new one, create another `.md` file inside `content/personal-projects` and place its images under `public/projects`.
